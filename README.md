# Espada OS

A public portfolio implementation of the Espada OS interface concept, focused on mobile shell interactions and visual system design.

## What It Is

Espada OS is a UI / interaction prototype. It is not a real operating system.

## Why I Built It

The project explores how mobile shell surfaces such as the launcher, dock, control center, and app surfaces can be composed into a consistent interaction model.

## Features

- **App Launcher Grid:** Interactive application icons and arrangement mimicking mobile home screens.
- **Dock Interaction:** Persistent quick-access application dock with responsive tap states.
- **App Sheets:** Fluid modal sheets and transitions simulating app opening and closing.
- **Control-Center Panel:** Quick settings surface for toggles, brightness, and status indicators.
- **Theme Switching:** Clean toggle between light and dark visual themes across all surfaces.
- **Responsive Mobile Presentation:** Designed with mobile-first viewport constraints and touch-friendly targets.

## Tech Stack

- **Frontend:** React, TypeScript
- **Tooling & Build:** Vite
- **Styling:** CSS
