# Espada OS

    A clean portfolio reconstruction created from the project's documented feature set.

    ## Run locally

    ```bash
    npm install
    npm run dev
    ```

    ## Build

    ```bash
    npm run build
    ```


## Portfolio notes
- Mobile OS interface concept
- App grid and dock interactions
- Control-center style panel
- Light/dark theme switching
- App surface transitions

This is a UI/interaction prototype rather than a real operating system.
